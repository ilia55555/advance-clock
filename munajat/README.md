# مناجات‌های قابل دانلود

فایل‌های MP3 مناجات را در این پوشه قرار دهید. فهرست `munajat.json` (نام، حجم و SHA-256 هر فایل) باید کنار آن‌ها باشد.
اپ این فهرست و فایل‌ها را از ریپوی عمومی `infinitimeilia/infinitime`، شاخهٔ `main`، پوشهٔ `munajat/` دانلود می‌کند.

مناجات پیش‌فرض داخل اپ: فایل را با نام `munajat_before.mp3` در `app/src/main/res/raw/` قرار دهید.
