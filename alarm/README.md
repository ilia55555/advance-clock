# صداهای هشدار InfiniTime

## ۱۲ صدای داخلی برنامه

این ۱۲ صدا باید همراه APK باشند؛ کاربر برای انتخاب یا پخش آن‌ها به اینترنت یا دانلود جداگانه نیاز ندارد.
فایل‌های MP3 را در پروژهٔ اندروید، کنار فایل‌های صوتی فعلی قرار دهید:

```text
advance-clock/app/src/main/res/raw/
```

نام فایل منبع اندروید باید با حروف کوچک انگلیسی و زیرخط باشد؛ نام‌های فعلی شامل فاصله و حروف بزرگ هستند و باید طبق جدول تغییر کنند.

فهرست داخلی در `app/src/main/res/raw/bundled_alarms.json` پروژهٔ اپ قرار دارد و نام‌های فارسی، انگلیسی و عربی را نگه می‌دارد. این فهرست داخل APK است و اپ برای خواندن آن به GitHub وصل نمی‌شود.

کد اپ برای این نام‌ها آماده است. تا وقتی فایل MP3 متناظر اضافه نشده باشد، گزینهٔ آن در فهرست ظاهر نمی‌شود؛ فایل صوتی ساختگی یا خالی نسازید. فایل‌های فعلی را حذف یا جایگزین نکنید. پس از کپی هر ۱۲ فایل، Debug و Release بسازید و پخش صداها را روی گوشی بررسی کنید.

در بخش انتخاب صدا، این موارد کنار صداهای قبلی برنامه نمایش داده می‌شوند. نام‌های منبع با `alarm_` شروع می‌شوند و در پیکربندی فعلی از حذف توسط Resource Shrinker نسخهٔ Release محافظت می‌شوند.

## صداهای قابل دانلود در آینده

این بخش برای صداهای اضافه‌ای است که نمی‌خواهید داخل APK قرار بگیرند. ریپوی عمومی انتشار:

https://github.com/infinitimeilia/infinitime

روی شاخهٔ `main`، فایل‌ها را در همین پوشه قرار دهید:

```text
alarm/
  alarms.json
  New Sound.mp3
  Another Sound.mp3
```

نام فایل‌های دانلودی می‌تواند فاصله داشته باشد، ولی باید انگلیسی، با پسوند `.mp3` و حداکثر ۲۰ مگابایت برای هر فایل باشد. این نام‌ها با نام منابع `res/raw` فرق دارند.

### تولید فهرست دانلود

ابزار ویندوزی در ریپوی کد اپ موجود است:

https://github.com/ilia55555/advance-clock/blob/Ilia/tools/create_sound_catalog.ps1

فایل `create_sound_catalog.ps1` را کنار MP3های دانلودی قرار دهید. در CMD همان پوشه اجرا کنید:

```bat
powershell -NoProfile -ExecutionPolicy Bypass -File ".\create_sound_catalog.ps1" -Folder "."
```

ابزار، `alarms.json` را با فیلدهای `schemaVersion` و `sounds` تولید می‌کند. هر صدا باید `id`، `name`، `file`، `version`، `size` و `sha256` داشته باشد. اندازه و SHA-256 باید از خود MP3 محاسبه شوند؛ مقدار فرضی ننویسید. JSON قدیمی که فقط `alarms` و ترجمهٔ نام‌ها را دارد، فهرست دانلود معتبر نیست.

اگر از قبل `alarms.json` وجود داشته باشد، ابزار یک نسخهٔ پشتیبان با نام `alarms.json.backup` می‌سازد. فقط MP3ها و JSON تازه را در این پوشه آپلود کنید؛ ابزار و فایل پشتیبان لازم نیست منتشر شوند.

### افزودن یا به‌روزرسانی صدا

1. MP3 جدید را به پوشه اضافه کنید، یا برای به‌روزرسانی، محتوای فایل موجود را با همان نام فایل جایگزین کنید.
2. ابزار را دوباره اجرا کنید؛ با تغییر محتوای فایل، نسخهٔ همان صدا افزایش می‌یابد.
3. MP3های جدید یا تغییریافته و `alarms.json` جدید را روی شاخهٔ `main` منتشر کنید. فایل‌هایی را که هنوز در فهرست هستند حذف نکنید.
4. کاربر در نسخه‌ای از اپ که این قابلیت را دارد، از بخش انتخاب صدا روی «بررسی صداهای قابل دانلود» می‌زند و برای هر مورد «دانلود» یا «به‌روزرسانی» را انتخاب می‌کند.

نشانی ثابت فهرست:

https://raw.githubusercontent.com/infinitimeilia/infinitime/main/alarm/alarms.json

بررسی و دریافت صداها دستی است؛ دانلود خودکار یا بررسی دوره‌ای در پس‌زمینه انجام نمی‌شود. فایل دریافت‌شده پس از بررسی اندازه و SHA-256 در حافظهٔ خصوصی اپ ذخیره و آفلاین پخش می‌شود. در به‌روزرسانی، مسیر محلی صدا ثابت می‌ماند و در صورت شکست دریافت یا اعتبارسنجی، فایل قبلی حفظ می‌شود. این بررسی‌ها سلامت دریافت و محدودبودن منبع را کنترل می‌کنند و جای محافظت از حساب GitHub را نمی‌گیرند.

برای افزودن صداهای دانلودی جدید، نیازی به انتشار APK جدید نیست. برای افزودن صداهای داخلی جدید، باید APK جدید ساخته و نصب شود.
